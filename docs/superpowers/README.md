# Registros históricos de desenvolvimento

Este diretório preserva decisões e evidências do trabalho documental executado com Superpowers. Os documentos são registros históricos, não instruções de trabalho pendente.

- `specs/` registra o contexto, as decisões e os critérios de aceitação aprovados na data indicada.
- `plans/` registra como a execução concluída foi decomposta, validada e entregue.
- Restrições de escopo descritas nesses arquivos valem para o patch histórico correspondente, salvo quando o próprio registro indicar uma consolidação posterior.

## Trabalho posterior

Documentos com datas posteriores devem declarar o próprio status. Antes de reutilizar um plano, confira o estado atual da branch, os metadados dos guias e as políticas vigentes na raiz do repositório.
